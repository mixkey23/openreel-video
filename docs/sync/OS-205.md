# OS-205 — Contrato `addClip` con duración y `setClipAudioPlan`

**Estado:** ✅ en verde · `apps/web/src/stores/framesmith-store-contract.test.ts` (8 tests)

Fija: `addClip(track, media, start, duration)` respeta `duration` (2,25 s frente a los 3,2 s del medio); sin duración o con `0` usa la del medio; una duración mayor que el medio **no** se recorta (11,667 s); `setClipAudioPlan` aplica volumen **acotado a 0…4**, `fade` (negativos → 0), `volumeAutomation` acotada y `metadata` fusionada, y devuelve `false` si el clip no existe; `renameTrack` renombra (síncrono o asíncrono: el test hace `await Promise.resolve(…)` para no depender del tipo de retorno); existen `loadProject/importMedia/moveClip/addTrack/removeClip/getClip/createNewProject`.

**Mutación comprobada:** quitando `params.duration = duration` fallan 2 tests de store y el de init (audio de 3 s en vez de 7,5 s).
